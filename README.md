# دليل أبنائنا بالخارج — خطوات البناء والنشر

التطبيق جاهز بالكامل. GitHub هو اللي هيبني ملفات أندرويد (AAB للمتجر و APK للتجربة) أوتوماتيك ومجانًا، وكمان هو المكان اللي هتحدّث منه الأخبار.

## الجزء الأول: رفع المشروع على GitHub (مرة واحدة)

1. ادخل على github.com واعمل حساب لو مش عندك.
2. اضغط **New repository**:
   - الاسم: `dalil-abnaana`
   - اختار **Public** (لازم يكون عام عشان التطبيق يقدر يقرا ملف الأخبار).
   - اضغط **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file**.
4. فك ضغط ملف `dalil-abnaana-project.zip` على الكمبيوتر، وافتح الفولدر، واسحب **كل اللي جواه** (مش الفولدر نفسه) لصفحة الرفع، واضغط **Commit changes**.
5. اتأكد إن فولدر `.github` اترفع. لو مش ظاهر في المستودع:
   - اضغط **Add file ← Create new file**.
   - في خانة الاسم اكتب بالظبط: `.github/workflows/build.yml`
   - افتح ملف `build.yml` من الفولدر بالمفكرة (Notepad)، انسخ محتواه كله والصقه، واضغط **Commit changes**.

## الجزء الثاني: إضافة مفتاح التوقيع (مرة واحدة)

مفتاح التوقيع هو اللي بيثبت لجوجل إن التحديثات جاية منك. هتلاقيه في ملف `مفاتيح-التوقيع-سري.zip`.

1. في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**.
2. أضف سرّين:

| الاسم (Name) | القيمة (Secret) |
|---|---|
| `KEYSTORE_BASE64` | انسخ محتوى ملف `KEYSTORE_BASE64.txt` كله |
| `KEYSTORE_PASSWORD` | انسخ محتوى ملف `KEYSTORE_PASSWORD.txt` |

⚠️ احتفظ بملف `مفاتيح-التوقيع-سري.zip` في مكان آمن (Google Drive مثلًا) ومتشاركهوش مع حد. لو ضاع، مش هتقدر ترفع تحديثات للتطبيق غير بعد طلب إعادة تعيين من جوجل.

## الجزء الثالث: بناء التطبيق

1. افتح تبويب **Actions** في المستودع. لو طلب تفعيل، اضغط **I understand… enable them**.
2. اختار **Build Android App** من القائمة، واضغط **Run workflow ← Run workflow**.
3. استنى حوالي 8 دقايق لحد ما تظهر علامة ✅ خضرا.
4. ادخل على **Releases** (على يمين صفحة المستودع الرئيسية). هتلاقي:
   - ملف `.apk` ← نزّله على موبايلك وجرب التطبيق.
   - ملف `.aab` ← ده اللي هترفعه على Google Play Console.

كل مرة تعدّل أي ملف في التطبيق، GitHub هيبني نسخة جديدة برقم إصدار أكبر تلقائيًا.

## الجزء الرابع: تحديث الأخبار من موبايلك (بدون تحديث التطبيق)

1. افتح ملف `news.json` في المستودع واضغط علامة القلم ✏️.
2. عشان تضيف خبر، انسخ الكتلة دي وحطها **أول** القائمة بعد `"news": [`:

```json
    {
      "id": "n7",
      "date": "2026-11-01",
      "cat": "exams",
      "title_ar": "عنوان الخبر بالعربي",
      "title_en": "News title in English",
      "body_ar": "تفاصيل الخبر بالعربي.",
      "body_en": "News details in English.",
      "source": "اسم المصدر",
      "url": "https://رابط-المصدر"
    },
```

- `id`: رقم مختلف لكل خبر (n7، n8، ...).
- `cat`: واحدة من `exams` (امتحانات) أو `consular` (قنصلية) أو `community` (الجالية).
- غيّر `"updated"` فوق لتاريخ النهارده.

3. **أول ما الوزارة تعلن موعد الامتحانات:** في قسم `"exams"` اكتب التاريخ في `"date"` بالشكل `"2027-01-09"` وغيّر `"confirmed"` لـ `true`. العدّاد التنازلي هيظهر عند كل المستخدمين، والتذكير هيشتغل.
4. اضغط **Commit changes**. الأخبار بتوصل للمستخدمين أول ما يفتحوا التطبيق.

⚠️ خلي بالك من الفواصل `,` وعلامات التنصيص `"`. لو الملف فيه غلطة، التطبيق هيعرض آخر أخبار سليمة لحد ما تصلحه.

## الجزء الخامس: الإعلانات (AdMob)

التطبيق شغال بإعلانات تجريبية لحد ما تحط أرقامك:

1. في admob.google.com أضف تطبيق أندرويد جديد، وبعدين أضف وحدة إعلانية من نوع **Banner**.
2. في المستودع: **Settings ← Secrets and variables ← Actions ← تبويب Variables ← New repository variable**:

| الاسم | القيمة |
|---|---|
| `ADMOB_APP_ID` | رقم التطبيق (شكله `ca-app-pub-xxxx~yyyy`) |
| `ADMOB_BANNER_ID` | رقم وحدة البانر (شكله `ca-app-pub-xxxx/zzzz`) |

3. شغّل البناء تاني من **Actions**.

الإعلانات بتظهر في قسم الأخبار بس، بعيد عن صفحات الامتحانات.

> يدعم العربية والإنجليزية، ومن غير تسجيل دخول.
